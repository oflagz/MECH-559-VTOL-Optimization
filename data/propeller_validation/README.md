# Propeller validation input format

Provide **independent measured** propeller performance data, not values
generated by this BEMT model.

Required CSV headers:

```
rpm,velocity_mps,thrust_n,power_w,radius_m,chord_m,twist_deg,blades,density_kg_m3
```

Optional: `theta75_deg`.

The current geometry interface assumes constant chord and linear twist.
Actual manufacturer propellers may have variable chord and nonlinear twist;
those must be represented before claiming quantitative validation.

Polar file headers:
```
reynolds,alpha_deg,cl,cd
```

Run:
```bash
python -m scripts.validate_propeller_data data/airfoil_polars/selected.csv data/propeller_validation/measurements.csv
```

The script reports prediction errors and convergence. It does not calibrate
against the test set or automatically establish model validity.
